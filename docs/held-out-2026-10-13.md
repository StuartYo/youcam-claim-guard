# Held-out photos (2026-10-13 evening)

Twelve selfies of the same face, taken on a different evening from the first 15, in one room. Converted with metadata stripped and analyzed with YouCam SD skin analysis (moisture, pore, wrinkle, radiance), 12 calls. The version 1 capture limits were frozen from sessions 1 to 3 before these photos were taken. These photos then showed why version 1 blocked same-lamp pairs, which led to version 2 (below). So they are a strict held-out set for version 1 only.

## Capture check

`npm run calibrate` reproduces both versions.

### Version 1, limits frozen (strictly held out)

Version 1 had four checks: face brightness on its own, face vs background ratio, backlight, and light colour measured as the red/blue ratio of the face.

| Pairs (ordered) | Expected | Result | Failed checks (pairs per check) |
|---|---|---|---|
| A-A | pass | 12/12 pass | none |
| B-B | pass | 8/12 pass | face brightness 4 |
| C-C | pass | 12/12 pass | none |
| A-B | blocked | 32/32 blocked | face brightness 32, light colour 32, face vs background 18 |
| A-C | blocked | 32/32 blocked | face brightness 32, light colour 32, face vs background 6 |
| B-C (same lamp, skin changed) | pass | 10/32 pass | light colour 15, face brightness 7 |

Before the change (version 1, limits frozen from sessions 1 to 3, 12 held-out photos): 32 of 36 same-setup pairs pass (88.9%); the 4 failures are all in setup B (desk lamp), on face brightness. 64 of 64 pairs with different light are blocked (100.0%). Same lamp, before and after moisturizer: 10 of 32 pairs pass (31.3%); the others fail on light colour in 15, face brightness in 7.

What this showed:

- Every pair where the light changed was blocked.
- Between B and C the lamp was the same, but the face measured redder after washing and moisturizer (face R/B about 1.60 in B, 1.63 to 1.66 in C), and the light colour check read that as warmer light. From the face alone it cannot tell skin colour from light colour. We did not test why the face measured redder.
- Face brightness moved from shot to shot under the same lamp (face luma 86 to 100 in B), partly with the phone's exposure.

### Version 2, the current check

Two changes, both about what is measured:

- Light colour is the red/blue ratio of the background strips beside the head (blown-out pixels left out). Skincare does not change the wall.
- Face brightness is divided by background brightness, so a uniform exposure change cancels out. That quantity is the old face vs background ratio, so version 2 drops that check and keeps three: face brightness relative to background, backlight, light colour.

The limit values stay at 10%, 15% and 2%. They were checked against sessions 1 to 3 only (same-spot retakes largest 5.7% and 1.0%; all 210 in-sample pairs still sort as before) and were not tuned on these photos or to make any case pass.

Which data informed what: sessions 1 to 3 set the limit values for both versions. Session4 showed the version 1 failure and so informed the choice of what to measure in version 2. Session4 is therefore not a strict held-out set for version 2, and its version 2 numbers below are reported as a re-run, not as a held-out accuracy figure.

| Pairs (ordered) | Expected | Result | Failed checks (pairs per check) |
|---|---|---|---|
| A-A | pass | 12/12 pass | none |
| B-B | pass | 8/12 pass | face brightness 4 |
| C-C | pass | 12/12 pass | none |
| A-B | blocked | 32/32 blocked | face brightness 32, light colour 32 |
| A-C | blocked | 32/32 blocked | face brightness 32, light colour 32 |
| B-C (same lamp, skin changed) | pass | 26/32 pass | face brightness 6 |

After the change (version 2, same 12 photos, no longer strictly held out): 32 of 36 same-setup pairs pass (88.9%); the 4 failures are all in setup B (desk lamp), on face brightness. 64 of 64 pairs with different light are blocked (100.0%). Same lamp, before and after moisturizer: 26 of 32 pairs pass (81.3%); the others fail on face brightness in 6.

The remaining failures are real measurements: in B the face got brighter relative to the background from shot to shot under the same lamp (ratio 0.414 to 0.475). We did not test why; head position relative to the lamp is one possibility. For a user they mean a "retake in the same light" prompt, not a wrong badge.

## Noise floor

The within-set spread was larger than in session1. Under the floor from session1 alone, 6 of 18 same-setup held-out pairs (unordered) moved moisture past it, 4 of 18 pore, 10 of 18 wrinkle and 2 of 18 radiance, where about 1 in 20 is expected. That floor was too tight.

Decision: pool the SD within all five sets of same-setup retakes (session1, session3, A, B, C). Each set keeps its own mean, so a lighting difference between sets never counts as noise. The window session stays out because every photo in it is backlit and the capture check blocks those pairs anyway. A pooled SD over more sets, days and setups is a more honest estimate of retake noise than one set of six. The cost: these photos now help set the floor, so the floor is no longer tested on held-out data. With the pooled floor, 3, 3, 3 and 0 of the 18 pairs still move past it for moisture, pore, wrinkle and radiance, so it may still be too tight.

|---|---|---|---|---|---|---|---|---|
| Moisture | 1.85 | 1.19 | 3.75 | 3.31 | 2.25 | 2.56 | 7.10 | 5.14 |
| Pore | 1.03 | 4.37 | 6.02 | 1.04 | 0.71 | 3.22 | 8.93 | 2.87 |
| Wrinkle | 0.06 | 0.34 | 1.23 | 0.18 | 0.08 | 0.55 | 1.51 | 0.17 |
| Radiance | 1.22 | 0.55 | 1.41 | 1.62 | 1.85 | 1.38 | 3.83 | 3.38 |

## Demo cases from these photos

Each case uses the shot closest to its group mean on the four raw scores (sum of squared differences divided by the pooled SD; `representative()` in `lib/noise-groups.ts`). The rule looks at scores only, never at capture stats or verdicts. A: IMG_1437. B: IMG_1432. C: IMG_1442.

**Same room, ceiling light to desk lamp (IMG_1437 to IMG_1432), the hero case.** Moisture ui 70 to 75 (raw +12.38 against 7.10), wrinkle ui 86 to 96 (raw +5.23 against 1.51): a noise check alone would show both badges. The capture check blocks the pair under both versions. Version 2: face 23.2% darker relative to the background, background light colour 7.4% warmer. The lamp photos were taken a few minutes before the ceiling ones; the case orders them ceiling to lamp, the direction that shows a gain. Reversed, it shows a drop of the same size.

**Real moisturizer, same lamp (IMG_1432 to IMG_1442), `product_category: "moisturizer"`.** One person, one application, photos about 20 minutes later.

| Metric | Before ui / raw | After ui / raw | Δraw | Pooled MDC95 | Verdict |
|---|---|---|---|---|---|
| Moisture | 75 / 62.72 | 75 / 63.75 | +1.03 | 7.10 | within-noise |
| Pore | 72 / 60.36 | 77 / 71.22 | +10.85 | 8.93 | blocked-claim-type |
| Wrinkle | 96 / 98.50 | 97 / 98.88 | +0.38 | 1.51 | blocked-claim-type |
| Radiance | 80 / 79.37 | 78 / 74.49 | −4.88 | 3.83 | claimable drop, no badge |

Version 1 blocked this pair because the face measured 10.1% brighter (limit 10%) under the same lamp. Version 2 passes it: face brightness relative to the background +8.9%, background light colour +0.5%. The limit did not move; the measurement did. Either way there is no moisture badge: moisture moved inside the noise floor. Radiance fell by more than retake noise, which Claim Guard reports as a real drop with no badge. This is one application after 20 minutes on one person; it says nothing about the product over weeks.
